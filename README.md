# git diff
Команда git diff показывает разницу между файлами в разных состояниях. Она подсвечивает, какие строки кода вы добавили (зеленым цветом с плюсом +) или удалили (красным цветом с минусом -).
Зачем нужна: Чтобы проверить себя перед коммитом и точно знать, что именно вы изменили в проекте.

Частые примеры использования:

* __`git diff` — показывает изменения в файлах, которые вы отредактировали, но еще не добавили в индекс (то есть до того, как вы написали git add)__.
* __`git diff --staged (или --cached)` — показывает изменения в файлах, которые вы уже добавили в индекс через git add, но еще не закоммитили.__
* __`git diff имя_ветки1 имя_ветки2` — показывает разницу между двумя ветками целиком (например, git diff main feature).__
* __`git diff ID_коммита1 ID_коммита2` — показывает, что изменилось между двумя конкретными точками в истории.__

# find (глубокий поиск по параметрам)
* Найти файл по имени в текущей директории и подпапках
  * __`find . -name "myfile.txt"`__
* Найти все .log файлы, изменённые за последние 7 дней
	* __`find /var/log -name "*.log" -mtime -7`__
* Найти и удалить все .tmp файлы (осторожно!)
	* __`find . -name "*.tmp" -delete`__
	
# locate (быстрый поиск по базе данных)
 Обновить базу данных (нужно для актуальности)
* __`sudo updatedb`__
 Найти файл по имени
* __`locate myfile.txt`__

# tree (вывод структуры в виде дерева)
Arch linux докачать если нет
* __`sudo pacman - S tree`__
* __`tree (Показывает просто дерево папки все файлы и подпапки)`__
* __`tree -d (Показывает только папки)`__
* __`tree -L 2 (Показывает два уровня)`__
* __`tree -a (Отображает также и скрытые файлы)`__


# file (определение типа файла)
Проверяет содержимое файла и выдает его тип. Даже если у него нет расширения

* __`file [опции] путь_к_файлу`__

* __`file image — (Проверит содержимое файла image и выдаст реальный тип)`__
* __`file script.sh — (покажет тип скрипта и на каком языке он написан)`__
* __`file -i archive.zip — (выведет тип файла в формате MIME)`__

# stat (детальные метаданные и даты)
* __` stat document.txt` — (выведет полную информацию: размер в байтах, количество занимаемых блоков, права доступа (в числовом и буквенном виде), UID/GID владельца и 3 главных временных метки (Access, Modify, Change)).__

# ln (cоздание ссылок / ярлыков)
* __`ln -s /var/www/my-site/ ~/Desktop/site-shortcut` (создать символическую ссылку (`-s` — мягкая ссылка/ярлык) на папку сайта прямо на рабочем столе. Если удалить ярлык, папка останется целой.)__

* __`ln photo.jpg backup_photo.jpg` (создать жесткую ссылку (hard link). Файл продублируется в файловой таблице, но физически на диске останется в одном экземпляре. Если удалить оригинал photo.jpg, файл все равно будет доступен по ссылке backup_photo.jpg)__
